# Frontend Coursework

A collection of frontend labs and homework created during Code Academy training. The repository contains independent HTML, CSS, Bootstrap, and JavaScript exercises ranging from basic page structure to DOM interactions and browser APIs.

[View the live project catalog](https://smr-25.github.io/Frontend/) · [Browse the source code](https://github.com/Smr-25/Frontend)

## Overview

| Category | Count |
|---|---:|
| Labs | 2 |
| Homework collections | 16 |
| Runnable exercise pages | 31 |
| HTML files including the catalog | 32 |
| JavaScript files | 14 |

All exercises are static and can run directly in a browser. No package installation or build step is required.

## Technology stack

- HTML5 and semantic page structure
- CSS3, Flexbox, Grid, positioning, and responsive styles
- Bootstrap layouts and components
- JavaScript fundamentals and algorithms
- DOM manipulation and browser events
- Local Storage and drag-and-drop APIs
- Fetch, Axios, and jQuery AJAX

## Run locally

Clone the repository and open the root `index.html` file:

```bash
git clone https://github.com/Smr-25/Frontend.git
cd Frontend
open index.html
```

Alternatively, serve the repository with any static file server. Individual exercises can also be opened directly from their own HTML files.

Some exercises use external fonts, images, CDN libraries, or public APIs and require an internet connection for those resources.
